# Words the owner already knows

`/explain` reads this list and does not explain these again. A word belongs here when the owner has said it is clear, or uses it correctly in their own words. One line each: the word, and the explanation or moment it was learned from.

- **Migration:** a numbered, written change to the database, applied in order (the owner applies them).
- **Backup:** Sunday's encrypted copy of contributions in R2, opened only with the owner's private key.
- **Turnstile:** Cloudflare's check that a person, not a bot, is signing in or saving for the first time.
- **Hook:** a reusable piece of screen logic in React, such as `useFixWrites`.
- **API call:** the app asking a server for data, or sending it some.
- **Environment variable (env):** a setting that differs per place (live, staging, a laptop), kept out of the code.
- **Byte:** 8 bits; the unit storage is counted in (the PMTiles "basics").
- **Server:** a program that waits for requests and answers them (the PMTiles "basics").
- **Fetch:** one request from the phone to a server and its answer, over HTTP (the PMTiles "basics").
- **Index:** a list that says where things are, so nothing has to be searched (the PMTiles "basics").
