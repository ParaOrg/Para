# Good first issues

Small, real tasks for people sending their first pull request. Each one is a file in `issues/`, written so that someone new to React and to jeepneys can finish it in an evening.

How to take one: read [CONTRIBUTING.md](../../CONTRIBUTING.md), comment on the matching GitHub issue (the maintainers copy these tickets there with the `good first issue` label), then open your pull request into `staging`.

Every ticket was checked against the code on 2026-10-26 (staging at c4f6bf9f). If a ticket is already fixed when you open it, say so in the issue; it is our mistake.
