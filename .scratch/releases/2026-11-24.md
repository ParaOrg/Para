# Release of 2026-11-24: staging into main

`staging` at #1181 (`0b93b43`) into `main`. `main` was last released on 2026-11-14 (#995); since then it took only Coming soon (#1127) and the retired installed map (#1129), both already back-merged into `staging` (#1128, #1130). `main` has no commit that `staging` lacks, so the pull request merges cleanly. 120 merged pull requests, #1053 to #1181.

## Who sees what

- **Commuters at www.para-commute.org still see Coming soon.** The site Worker answers every map address on the production hosts with Coming soon, whatever the build holds (#1127). So the commuter map's changes below go live on `main` but stay behind Coming soon until the owner lifts it. Staging and every Preview keep showing the map.
- **The studio** (`/studio/`) and **the contributor page** (`/contribute/`) are live on production, so their changes reach editors and contributors with this release.
- **The contributor app** (Android) changed: its native side gains a Back plugin, so the phone's Back closes the top layer first, and the contributor page's changes ride into it. A new `app-v*` tag is a separate step after the merge (see below).
- **Tiles:** `para-tiles` deploys from `staging`, so #637 is already live.

## On screen

### Commuter map (behind Coming soon on production)

- **New RouteDetail and RouteCard** (#1082 to #1104, #1121, #1155): the ends card, destinations, signboard, tiles, stops, loops and trains, restyled to the owner's Figma; RouteCard rows as Figma draws them.
- **Map mechanics** (#1125, #1141): no bottom bar; Vice Versa, filter and Overview on the map; the ⓘ top left; the map's controls in one column on the left; tap the map to leave a trip.
- **Camera** (#1095, #1102, #1175): choosing a route never moves the map; Overview frames it when pressed. Choosing a place, a hotspot, search and the locator still move it.
- **Sheets** (#1100, #1151, #1153, #1170, #1176): momentum, no lag, a picked trip glides in, a tap after the keyboard lands where it was made, and a flick down on a short list rests low instead of closing.
- **Route list** (#1174): ends at its last card; long names whole.
- **Taps** (#1137, #1168): a tap clearly nearest one route opens it; the list only when it's ambiguous. Hotspots take no tap for now.
- **Arrows** (#1178): they flow for 3 seconds when a route lights, then rest until the map is touched.
- **Establishments** (#1142, #1143, #1148, #1152): the basemap's places as markers with Location Labels; pawnshops, remittance and bayad centers at close zoom from monthly cell files.
- **Fonts** (#1099): Livvic everywhere; SN Pro retired.
- **Lighter first download** (#1179, #1181): place search, still off, is no longer downloaded at all: about 11 kB less.
