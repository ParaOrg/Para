# Release of 2026-11-26: staging into main

`staging` at #1245 (`8f7a989`), plus this summary, into `main`. `main` was last released yesterday (#1205); since then it took only the nightly Publish map run of 2026-11-26 02:39 UTC, whose files `staging` already holds (f1d8b57, the publish's own copy). A trial merge of `staging` into `main` is clean and leaves exactly `staging`'s tree. 35 merged pull requests, #1204 to #1245, with yesterday's back-merge (#1207).

The owner asked for this release today. Three reasons:
- `main`'s publish code has no shape 6 (`index.v6.json`), so each nightly copy onto `staging` leaves `staging`'s v6 behind its other files (staging red at f1d8b57, fixed by #1243);
- `main`'s publish code does not know the mode `busway`, so a published EDSA Carousel route would fail the nightly publish;
- it brings `main` the fixes its own push CI is red without (#1218, #1227, #1229).
