# Release of 2026-11-28: staging into main

`staging` at `85d7a78f`, plus this summary, into `main`. `main` was last released yesterday (#1267, the merge of 2026-11-27's notes). Since then `main` took one commit, "Publish map 2026-11-28 02:29 UTC", and `staging` already carries the same data as "Publish map ... (data only, from main)". A trial merge of `staging` into `main` is clean. 20 merged pull requests, #1274 to #1294 (one of them the back-merge of `main`, #1274). No database change.

## Who sees what

- **Commuters at www.para-commute.org still see Coming soon** (#1127). The commuter map's changes below go live on `main` but stay behind Coming soon. Staging and every Preview show the map.
- **The studio** (`/studio/`): a tap opens a route's or hotspot's detail, and editing starts only from Edit. A route can be started from an old Para route. On a computer the route list fills the left panel.
- **The contributor page** and **the contributor app** (Android): no change.
- **Database:** nothing new. `supabase/migrations` is identical on `staging` and `main`.

## On screen

### Studio

- **Detail first** (#1277, #1279, #1280): a tap opens the route's or hotspot's detail, and editing happens only from Edit. A draft-only slot opens its draft, dashed-line taps are kept, and a draft-only route has no Extend. The detail is a summary card with Origin, Destination, Via and Status.
- **Place card** (#1282): a hotspot or terminal that exists only in a draft opens a card first (a stand-in).
- **Delete** (#1275, #1276): deleting a direction discards the editor's own draft of the route. The notice after a discard is honest about it, and the direction wording is fixed.
- **Route list on a computer** (#1278, #1281): the list fills the left panel and ends at its content, docked the way the public map docks it.
- **Start from an old Para route** (#1289, #1291): a route can be started from an old Para route. The three test rows are hidden, and the PDF gets a Mode column, verified first.
- **Route cards** (#1283, #1284, #1290): the public map's route cards and their controls moved into `routes`, and the studio now uses the same ones (step 3 of 3).

### Commuter map (behind Coming soon on production)

- No visible change of its own. Its route cards moved into `routes` for the studio to share (#1283, #1284). They are moves and extractions, not restyles.

## Behind the screen

- **Data:** "Publish map 2026-11-28 02:29 UTC" is already on `main`; `staging` holds the same data, so the merge adds nothing. (A back-merge, #1274, brought `main` into `staging`.)
- **Deploys and CI:** `ci.yml` runs `studio-old-para-start-test` beside `studio-osm-start-test` (#1294). This is a change to `.github/`, so after the merge `main`'s push run is the one to watch.
- **Tests:** the keystroke search is timed as the median of 7 runs (#1286). `save-drafts-test` waits for the chevrons, so the reload into a drawing settles (#1293).
- **Dev server:** it ignores the agents' worktrees (#1285), and only this checkout's own, not a worktree's own files (#1288).
- **Tidy:** what only the deleted Controller bar used is removed (#1292).
